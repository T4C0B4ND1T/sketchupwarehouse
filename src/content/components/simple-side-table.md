A minimal side table with a square top and four straight square legs. The top and legs use separate solid colors, so you can restyle them independently.

## How to use it

1. Download the .skp file and open it in SketchUp, or import it into your model with **File → Import**.
2. Use the **Paint Bucket** to swap the top and leg colors for your own materials.
3. Resize it with the **Scale** tool to fit your layout.
