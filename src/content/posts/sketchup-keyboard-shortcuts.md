SketchUp ships with single-key shortcuts for its core tools, and most of them are worth learning in your first week: <kbd>L</kbd> for Line, <kbd>R</kbd> for Rectangle, <kbd>P</kbd> for Push/Pull, <kbd>M</kbd> for Move. For everything else, you can assign your own keys in Preferences. The steps are almost the same on Windows and Mac.

The defaults below come from the official SketchUp Help Center. Tool behavior can differ slightly between versions, so check the help page for any tool you rely on heavily.

## Default shortcuts worth learning

You don't need all of them. Start with the drawing and modification tools you use in every model, then add navigation and organization.

### Selection and drawing

| Tool | Shortcut |
|---|---|
| Select | <kbd>Spacebar</kbd> |
| Lasso Select | <kbd>Shift</kbd> + <kbd>Spacebar</kbd> |
| Line | <kbd>L</kbd> |
| Rectangle | <kbd>R</kbd> |
| Circle | <kbd>C</kbd> |
| 2 Point Arc | <kbd>A</kbd> |

### Modifying geometry

| Tool | Shortcut |
|---|---|
| Move | <kbd>M</kbd> |
| Push/Pull | <kbd>P</kbd> |
| Rotate | <kbd>Q</kbd> |
| Scale | <kbd>S</kbd> |
| Offset | <kbd>F</kbd> |
| Eraser | <kbd>E</kbd> |
| Paint Bucket | <kbd>B</kbd> |
| Tape Measure | <kbd>T</kbd> |

### Navigation and organization

| Tool or command | Shortcut |
|---|---|
| Orbit | <kbd>O</kbd>, or click and drag with the middle mouse button |
| Pan | <kbd>H</kbd>, or <kbd>Shift</kbd> + middle-button drag |
| Zoom | <kbd>Z</kbd>, or the scroll wheel |
| Zoom Extents | <kbd>Shift</kbd> + <kbd>Z</kbd> |
| Make Component | <kbd>G</kbd> |
| Back Edges | <kbd>K</kbd> |
| Search for tools and commands | <kbd>Shift</kbd> + <kbd>S</kbd> |

The Select tool on <kbd>Spacebar</kbd> is the one that pays off most. You return to it constantly, and it's the easiest way to stop whatever tool you're in.

### A few habits that make these stick

- **Keep one hand on the keyboard and one on the mouse.** Tap the key, then click in the model. Moving to the toolbar every time is what slows most beginners down.
- **Use the scroll wheel and middle button for navigation.** You'll orbit, pan and zoom hundreds of times per model, so the mouse is faster than the keys. The keys are a fallback if you're on a trackpad.
- **Learn modifier keys per tool, not in general.** Modifiers change meaning between tools. With the Eraser, for example, <kbd>Shift</kbd> hides edges while <kbd>Ctrl</kbd> (<kbd>Option</kbd> on Mac) softens and smooths them. Read the Help page for each tool before you rely on a modifier.
- **Use Search as a safety net.** <kbd>Shift</kbd> + <kbd>S</kbd> lets you type the name of a tool or command and run it, which is handy for things you use rarely and don't want to give a shortcut.

## How to set your own shortcuts

SketchUp lets you assign keys to any tool or command in the Shortcuts section of Preferences, including ones that have no default key. The panel lists every command you can assign.

### On Windows

1. Choose **Window > Preferences** and select **Shortcuts**.
2. Type part of the command name into the filter box. For example, typing "make" finds **Edit/Make Group**. Typing "zoom" narrows the list to the Camera zoom commands.
3. Select the command in the **Function** list.
4. Click into the **Add Shortcut** field and press the key combination you want.
5. Click the **+** button to confirm. The new key appears under **Assigned**.
6. Click **OK** to close Preferences.

### On Mac

1. Choose **SketchUp > Settings** and select **Shortcuts**.
2. Use the search field to find the command.
3. Select the command so it's highlighted.
4. Click the text box in the lower-left of the panel and press the key combination you want.
5. Confirm the assignment. The shortcut shows in the **Key** column.

On both platforms the panel offers a **Reset All** button that restores the defaults, so experimenting is low-risk.

### Rules and limits

- **Shortcuts can't start with a number.** Numbers are reserved for specific commands and for typing values into the Measurements box.
- **You can add modifiers.** <kbd>Shift</kbd>, <kbd>Alt</kbd> and <kbd>Ctrl</kbd> can be combined with other keys.
- **You can't use keys your operating system reserves.** SketchUp warns you if your choice clashes with one.
- **Don't press <kbd>Enter</kbd> to confirm.** It clears the field. Use the **+** button instead.
- **Conflicts are your call.** If a key is already assigned, SketchUp asks whether to keep the original or replace it.

## Which shortcuts to add

Defaults cover the main tools. Consider assigning keys to commands you reach through menus several times an hour, such as:

- **Edit > Make Group**, if you group more often than you make components.
- **Camera > Zoom Window** or other Camera commands you use.
- **Edit > Hide** and **Unhide** items.
- Tools from your extensions, which usually appear in the same Shortcuts list once installed.

Choose letters that are close to your left hand and easy to remember, and avoid reassigning defaults unless you have a clear reason. If you share a computer or follow video tutorials, changed defaults will confuse you.

### Moving your shortcuts between computers

On Windows, the Help Center describes a way to import and export your shortcut preferences, which is useful if you work on a desktop and a laptop. The official Help article covers the steps. The Help Center marks this as a Windows-only feature, so Mac users should set up each machine by hand.

## Common mistakes

- **A shortcut does nothing.** SketchUp needs focus in the modeling window. Click once in empty space, then try again. If you were typing in a field such as the Measurements box, the key goes there instead.
- **Letters appear in the Measurements box.** You started typing a value while a tool wanted a number. Press <kbd>Esc</kbd> and begin again.
- **A custom shortcut stopped working after reinstalling.** Preferences may have reset. Reassign it, or import a saved shortcut file on Windows.
- **Shortcuts differ in SketchUp for Web.** The web version has its own shortcut page in the Help Center, so don't assume the desktop list applies exactly.

## FAQ

### What are the most useful SketchUp keyboard shortcuts?

<kbd>Spacebar</kbd> (Select), <kbd>L</kbd> (Line), <kbd>R</kbd> (Rectangle), <kbd>P</kbd> (Push/Pull), <kbd>M</kbd> (Move), <kbd>E</kbd> (Eraser) and <kbd>Shift</kbd> + <kbd>Z</kbd> (Zoom Extents) cover most day-to-day modeling.

### How do I change a keyboard shortcut in SketchUp?

Open **Window > Preferences > Shortcuts** on Windows, or **SketchUp > Settings > Shortcuts** on Mac. Select the command, type the new key combination, and confirm it. On Windows you confirm with the **+** button.

### Why won't SketchUp accept my shortcut?

It most likely starts with a number, or your operating system reserves it. Add a modifier such as <kbd>Shift</kbd> or <kbd>Ctrl</kbd>, or pick a different key.

### Can I reset SketchUp shortcuts to default?

Yes. Use **Reset All** in the Shortcuts section of Preferences to restore the default assignments. This removes your custom keys, so export them first on Windows if you want a backup.
