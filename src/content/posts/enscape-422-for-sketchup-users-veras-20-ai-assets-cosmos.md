Chaos released Enscape 4.22 on November 4, 2026. The headline changes are Veras 2.0 built into Enscape, a beta tool that generates a 3D asset from a reference image, a beta AI assistant, and image-based search in the Chaos Cosmos library. None of it is SketchUp-specific, but SketchUp is one of Enscape's host applications, so it all lands in your viewport.

The short version: the Cosmos search is the part most people will use this month. The AI generation tools are betas, so treat them as sketching aids, not production assets.

## What changed in Enscape 4.22

### Veras 2.0 inside Enscape

Veras is Chaos's AI tool for generating design variations from your model. According to [AEC Magazine](https://aecmag.com/visualisation/chaos-brings-ai-design-exploration-into-enscape/), Veras 2.0 is now integrated into Enscape, so you no longer open a separate Veras window. It is meant for testing materials and moods, and it adds new AI video models for presenting ideas.

Veras uses Chaos Credits. That matters if you are watching costs.

### AI 3D model generation (beta)

You can create a textured 3D asset from a reference image when the library has nothing suitable. It is free during the beta, within usage limits, and does not consume Chaos Credits. Chaos has not published polygon counts, texture resolution, accuracy targets or export formats, according to [Maverick Frame's write-up](https://maverickframe.com/blog/enscape-november-2026-update/). Without those numbers, I would use it for background clutter, not for a specified product or a close-up shot.

### Chaos AI Assistant (beta)

An in-product assistant that answers software questions and recommends Cosmos assets from a text prompt, a reference image or the active viewport.

### Image-based search in Cosmos

Instead of guessing keywords, you give Cosmos a reference picture and it finds visually similar assets. Maverick Frame reports the library now holds more than 13,000 assets, with over 1,500 new ones. This is a plain time-saver for anyone who populates interiors and landscapes.

### Smaller additions

- **Chaos Cloud:** uploads and PDF sharing, with renders, panoramas, scenes and web standalones managed in one place.
- **Composition gridlines:** viewport guides such as the rule of thirds.

Enscape Envision also got additions (guided camera viewpoints, asset scatter and others), but that is a separate product from the standard Enscape most SketchUp users run.

## The credits offer

Per AEC Magazine, eligible new Enscape trials and annual licence purchases get 500 extra Chaos Credits until November 15, 2026. Maverick Frame adds that for existing one-year licence holders, the credits go to the subscription and can be used for one month. If you were about to start a trial or buy a licence anyway, the deadline is days away. If you were not, don't let a credit bundle drive the decision.

## What it means for SketchUp users specifically

Enscape renders your SketchUp model live, so the Cosmos additions show up as assets you place in the model from within Enscape. Chaos's [Enscape feature page](https://www.chaos.com/enscape/latest-version) lists SketchUp 2026 as a supported host and does not mention SketchUp 2027.

That gap is worth flagging. [SketchUp 2027](/blog/sketchup-2027-is-out-procedures-mac-rebuild-intel-dropped/) shipped on October 21, 2026, and its [official release notes](https://help.sketchup.com/en/release-notes/sketchup-desktop-20270) say native C extensions must be rebuilt against Ruby 3.4, with the Ruby interpreter moving from 3.2.2 to 3.4.9. I could not find a statement from Chaos on Enscape support for SketchUp 2027 in the sources I checked, so confirm it in the Enscape release notes or on the Chaos download page before you move a live project.

If you are still choosing a renderer, our [Lumion vs Enscape comparison](/blog/lumion-vs-enscape-for-sketchup-users/) covers the trade-offs. Nothing in 4.22 changes that comparison much, apart from Cosmos getting easier to search.

### Worth it?

- **Time saved:** image search in Cosmos is the realistic win. Finding a matching chair or plant from a photo beats typing synonyms.
- **Cost:** the beta AI tools are free for now; Veras draws on Chaos Credits. Pricing for Enscape itself varies by licence, so check Chaos directly.
- **Who should skip it:** anyone mid-project on SketchUp 2026 or earlier who does not need Veras. Don't update a working render setup the week before a deadline.

## A safe way to try it

A repeatable setup beats a surprise mid-project. For a living room render, say, do this:

1. Copy your project folder and open the copy, not the original.
2. Update Enscape on a test install, not the machine you deliver from.
3. Open the Cosmos browser and try image search with a photo of a sofa you actually want.
4. Place the result, then compare file size and viewport performance against your current version.
5. Try Veras on one view only and note how many credits it uses.
6. Only then update your production machine.

If you keep older SketchUp versions around, remember that [2024 reaches end of support on January 31, 2027](/blog/sketchup-end-of-support-2024-ends-jan-31-2027-what-to-do/), which is a separate reason to plan your upgrade.

## What this means for you

- **Veras 2.0 inside Enscape:** try it if you already use AI concept renders; budget the credits first.
- **AI 3D model generation (beta):** ignore for deliverables, test for background objects.
- **Chaos AI Assistant (beta):** low stakes, try it when stuck.
- **Cosmos image search:** act now if you use Cosmos; it is the most practical change.
- **Credits offer:** act by November 15 only if you were buying or trialing anyway.
- **SketchUp 2027 compatibility:** verify with Chaos before upgrading a live project.

## FAQ

### When was Enscape 4.22 released?

November 4, 2026, according to the trade coverage and the Maverick Frame write-up cited above.

### Does Enscape 4.22 support SketchUp 2027?

I could not confirm it. Chaos's feature page lists SketchUp 2026 and does not mention 2027, so check the official Enscape release notes before updating.

### Is the AI 3D model generation free?

During the beta it is free, within usage limits, and does not use Chaos Credits. Veras does use credits.

### Do I need Veras to use Enscape?

No. Veras 2.0 is integrated, but it is an optional AI feature. Core Enscape rendering from your SketchUp model works as before.
